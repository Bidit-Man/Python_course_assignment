#  Data Scraping Assignment – Politics News

This project is a simple web scraping assignment that extracts the latest **political news articles** from **Onlinekhabar English**.

---

##  Features
- Extracts:
  - Title
  - Posted Date
  - Content
  - URL
  - Scraped Time
- Scrapes only the **latest 10 articles**
- Saves data in a **JSON file**

---

##  Source
https://english.onlinekhabar.com/category/political

---

##  Tech Used
-Python
-requests – for sending HTTP requests
-BeautifulSoup – for parsing HTML
-json – for storing data
-datetime – for timestamping
